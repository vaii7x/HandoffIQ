# Production-Ready Calculator

A robust, fully typed TypeScript calculator library implementing basic arithmetic operations with rigorous error handling.

## Features

- **Addition**: Add two numbers seamlessly (`R001`).
- **Subtraction**: Subtract numbers accurately (`R002`).
- **Multiplication**: Multiply numerical inputs (`R003`).
- **Division**: Divide numbers with explicit division-by-zero protection (`R004`).

## Installation & Usage

```bash
npm install
npm run build
npm test
```
