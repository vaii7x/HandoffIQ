# Python CLI Calculator

A clean, production-ready Python command-line calculator implementing basic arithmetic operations with an interactive user interface.

## Features

- **Addition (`R001`)**: Accurately adds two numerical inputs.
- **Subtraction (`R002`)**: Accurately subtracts the second numerical input from the first.
- **Multiplication (`R003`)**: Accurately multiplies two numerical inputs.
- **Interactive CLI (`R004`)**: Command-line loop allowing users to select operations and input numbers interactively.

## Installation & Running

Run the application from the root directory:

```bash
python main.py
```

## Running Tests

Execute the unit test suite using python's built-in unittest framework:

```bash
python -m unittest discover -s tests
```
